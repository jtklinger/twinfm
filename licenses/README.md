# Licenses of material built into twinfm.exe

TwinFM's own code is MIT (`LICENSE` at the repository root). The Rust crates are listed with their
licenses in `THIRD-PARTY-LICENSES.html` (generated by `cargo about`, `about.toml`). This folder
holds the texts that list does not carry:

| File | What it covers |
|---|---|
| `Slint-Royalty-free-2.0.md` | Slint (the `slint` and `i-slint-*` crates), used under its Royalty-free 2.0 license; copied from the Slint source at rev a1ce0d8 |
| `PDFium-Foxit-fonts.txt` | The substitute fonts for the 14 standard PDF fonts that the `hayro-interpret` crate embeds (from PDFium, BSD-3-Clause) |
| `Adobe-CMaps.txt` | The CMaps that the `hayro-cmap` crate embeds (Adobe, BSD-3-Clause) |
| `CGATS-CMYK-profile-CC0.txt` | The CMYK colour profile that `hayro-interpret` embeds (CC0-1.0) |

The interface font's license is `src/ui/fonts/OFL.txt` (Inter, SIL OFL 1.1) and the icons'
`src/ui/icons/LICENSE` (Lucide, ISC; Feather, MIT). `tools/package-release.ps1` puts all of these
in the release zip.
