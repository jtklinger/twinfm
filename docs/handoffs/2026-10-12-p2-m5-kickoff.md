## Gotchas hit this session

- **Scripted checks that call a callback directly prove nothing about real input.** The
  P2-M2 Escape regression (popups stopped closing) passed 83 tests and every scripted check
  because `crumbclose` called the close function. Demand one step through Slint's real key or
  pointer routing and a negative control. Real OS input can be posted to the TwinFM window with
  `PostMessageW` (`WM_MBUTTONDOWN`, `WM_XBUTTONDOWN`, `WM_KEYDOWN`): scratch `post_input.py` in
  the session's scratchpad did this; the memory note "SER5-DESK harness limits" is about
  SendInput, not posted messages.
- **Slint closes the topmost popup on Escape only if the focused item rejects the key.** A
  `return accept` on Escape in any FocusScope kills Escape for every popup in the app.
- **The everyday binary is not rebuilt by a merge.** `target\release` is whatever was built
  there last; twice a console check ran a pre-merge build. Rebuild after every merge and say so.
- **Paths handed to `twinfm.exe` from Git Bash must be Windows-style**: a forward-slash path
  reaches `SHParseDisplayName` and fails with 0x80070057, so a scripted drag silently never
  starts. Use `cygpath -w`.
- **PowerShell's `2>` redirect writes UTF-16 with wrapped lines**; convert with
  `iconv -f UTF-16LE -t UTF-8` before grepping.
- **Close every TwinFM window before a gate run.** A pre-existing window appears in the trace
  with start "MIN" and a window opened during the run goes to "MAX"; the analyzer now handles
  both, but the extra process still shares the machine.
- **One console WPR run resolves about two points on a busy day**, not the 0.3 assumed since
  P2-M1. Never judge a milestone on one pair; never compare against a recorded number from
  another session.
- **Logi Options+ remaps the middle button** and possibly the side buttons; when a physical
  button "does nothing" but a posted message works, look there first.
- **`gh pr merge` is blocked for the session**; `gh api -X PUT .../merge -f
  merge_method=squash` works on Jeremy's word, then delete the remote branch, pull main, remove
  the worktree.
- **Tell Jeremy the keystrokes a check needs** (Ctrl+T for a second tab, Ctrl+D for a bookmark,
  F3 to split). "Nothing to drag" was one tab per pane.
